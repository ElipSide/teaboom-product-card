# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: вёрстка верхней части карточки товара для [teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

**Демо:** https://elipside.github.io/teaboom-product-card/

**Репозиторий:** https://github.com/ElipSide/teaboom-product-card

## Запуск

Сборка не нужна. Можно просто открыть `index.html` в браузере.

Лучше запустить через локальный сервер:

```bash
python -m http.server 8000
# или
npx serve .
```

Затем открыть http://localhost:8000.

## Структура

```
├── index.html          разметка карточки
├── css/style.css       стили (mobile-first, BEM, CSS-переменные)
├── js/product.js       переключение фасовки, счётчик и мини-корзина
└── img/                фото товара (400 и 800 px для srcset)
```

## Что сделано

- **Семантика:** `main`, `nav` с крошками, `article` для товара, `figure`, `dl` для артикула и наличия, `s` для старой цены.
- **Выбор фасовки** сделан на нативных `radio` внутри `fieldset`/`legend`. Поэтому он работает с клавиатуры (стрелки, Tab) и понятен скринридерам без дополнительных ARIA-атрибутов.
- **Данные фасовок** хранятся в `data-*` атрибутах. JS только читает их и обновляет:
  - артикул;
  - цену и старую цену;
  - бейдж скидки;
  - цену за 100 г.

  В HTML уже есть значения для 100 г, так что без JS карточка тоже выглядит нормально.
- **Цены** форматируются через `Intl.NumberFormat('ru-RU')`: `326,40 ₽`, `1 432 ₽`. Блок цены помечен `aria-live`, так что скринридер озвучивает новую цену.
- **Кнопка «В корзину»** имеет состояния `hover`, `active` и `focus-visible`. После клика она заменяется счётчиком `[✓] [− N +]`:
  - количество считается отдельно для каждой фасовки, например 3 × 100 г, 1 × 500 г и 1 × 1000 г;
  - на кнопках фасовок появляется бейдж с числом упаковок в корзине;
  - под кнопкой выводится сводка корзины с суммой по каждой фасовке и итогом;
  - если уменьшить количество до нуля, возвращается кнопка «В корзину», а фокус переходит на неё;
  - корзина хранится в `localStorage` и не сбрасывается при перезагрузке. Настоящий бэкенд не подключён.
- **Адаптивность** построена на CSS Grid с `grid-template-areas`:
  - **1440 px:** фото слева (560 px). Справа друг под другом название, блок покупки и описание.
  - **768 px:** фото и блок покупки стоят рядом, описание занимает всю ширину под ними. Фасовки выстроены сеткой 2×2.
  - **375 px:** одна колонка. Название стоит над фото, чтобы сразу было видно, что это за товар. Крошки свёрнуты до ссылки «← на уровень выше». Кнопка растянута на всю ширину.
- **Стилистика Teaboom:**
  - фирменный жёлтый `#f5d730` для кнопки и выбранной фасовки;
  - тёмный текст `#202020`;
  - красная акционная цена;
  - шрифт Open Sans, как на сайте.
- Учтён `prefers-reduced-motion`. Картинка подключена через `srcset` и имеет явные `width`/`height`, чтобы вёрстка не прыгала при загрузке.
